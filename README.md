## 📂 Sections
- **Hero:** Quick introduction and links to GitHub/LinkedIn.
- **About:** Educational background and core engineering/software skills.
- **Experience:** Past and current professional experiences.
- **Projects:** A collection of hardware, software, IoT, and networking projects with interactive filters.
- **Certificates:** Professional certifications and achievements.
- **Contact:** Get in touch via email, phone, or location.

## 🚀 Getting Started Locally

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Oshadha-Nimantha/Portfolio.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd Portfolio
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
